# BetterPosters

Replaces Jellyfin movie/series posters with the ones generated by
[btttr.cc](https://btttr.cc) (Polish posters from `btttr.cc/poster/imdb/poster-default/{imdb_id}.jpg`).

Instead of overwriting every poster on each run, it keeps state in a local
SQLite database (`betterposters.db`) and only updates:

1. **new items** (not present in the database),
2. **items whose poster was changed by Jellyfin itself** (detected via the
   `ImageTags.Primary` hash, which changes whenever the image changes).

## Ready-made image

```bash
docker pull ghcr.io/hippo82/betterposters:latest
```

## Usage

### 1. Configuration

Create a `.env` file next to the compose file:

```env
SERVER_URL=https://your-jellyfin.example.com/jellyfin
API_KEY=your-api-key
RUN_INTERVAL_MINUTES=60   # how often to run (0 = run once and exit)
POSTER_LANG=en            # poster language for btttr.cc (default: en)
```

### 2. Run (NAS / server)

```bash
docker compose -f docker-compose.nas.yml up -d
```

The container stays up 24/7 and syncs posters every `RUN_INTERVAL_MINUTES`.
The SQLite database is persisted via a bind mount (`./betterposters.db`).

### 3. Run once (local, without Docker)

```bash
python main.py            # update only new / changed posters
python main.py --force    # update everything, ignoring the database
```

Requires Python 3.13+ and `uv` (or `pip install requests python-dotenv`).

## Docker image

Build and push your own image to GitHub Container Registry:

```bash
# once:
echo <TOKEN> | docker login ghcr.io -u <GHCR_USER> --password-stdin

# build + push:
./push.sh
```

Set `GHCR_USER` in `.env` (image name: `ghcr.io/<GHCR_USER>/betterposters:latest`).
